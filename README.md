## ⚡ About Me

I am a systems and platform engineer focused on high-throughput backend architecture, native spatial engines, and real-time AI/speech pipelines. As the founder of **Terrorify Studios** and **Minemares**, I design low-latency distributed networks that scale to thousands of concurrent users with zero-copy dataflow, mechanical sympathy, and bounded memory footprints.

My engineering philosophy prioritizes:
- **Zero-overhead performance:** Direct C-ABI FFI bindings, off-heap arena allocators, and minimal serialization bottlenecks.
- **Resilient distributed architectures:** Event-driven multi-instance session IPC, SpacetimeDB delta-log replication, and distributed tracing.
- **Autonomous AI orchestration:** Real-time multi-agent workflows, native Model Context Protocol (MCP) servers, and streaming neural speech pipelines.

## 🛠️ What I Build

### 🕹️ High-Performance Game Engines & Spatial Streaming
- **[Solar](https://github.com/McMmax/solar)**: Bounded per-chunk world persistence, LZ4 streaming world storage, and SpacetimeDB delta-log replication.
- **[Polar4D](https://github.com/McMmax/polar4D)**: Fast, compact 4D voxel world storage and continuous collision detection (CCD) for Minestom.
- **[Janitor](https://github.com/McMmax/janitor)**: Off-heap memory arena manager and direct memory lifecycle cleaner for high-throughput JVM runtimes.
- **[ACMD](https://github.com/McMmax/acmd)**: Unified cross-platform annotation-driven command dispatcher for Rust and Minestom.
- **[LightRace](https://github.com/McMmax/lightrace)**: Distributed context tracking and microsecond execution tracing across JVM and Rust FFI boundaries.

### 🎙️ AI Systems & Neural Speech Processing
- **[Transcripy](https://github.com/McMmax/transcripy)**: High-throughput real-time streaming speech-to-text engine with acoustic energy breath-aware buffering, NVIDIA NeMo / Whisper ASR, and lookahead phonetic correction caches.
- **[MeganCrush](https://github.com/McMmax/MeganCrush)**: Multi-model AI orchestrator built on Crush. Coordinates Claude, Gemini, and Codex CLIs via zero-dependency Python stdio MCP servers and Unix domain socket IPC.
